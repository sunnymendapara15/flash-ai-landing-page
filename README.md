# Flash, AI — Landing Page ⚡

A premium, conversion-focused landing page for **Flash, AI** — *describe your idea, build workflows with simple text conversation.*

Designed with the polish of leading tech brands: clean typography, generous whitespace, refined gradients, subtle glassmorphism, and smooth, elegant animations (scroll reveals, staggered entrances, hover effects, ambient motion, microinteractions).

## ✨ Highlights
- Sticky glass navbar with animated mobile menu
- Hero with live typing demo + gradient headline
- Social proof: logo marquee + animated stat counters
- Features bento grid with mouse-tracked hover glow
- Product showcase with staggered workflow nodes
- Benefits, testimonials, pricing (monthly/yearly toggle), FAQ accordion, CTA, footer
- Fully responsive, mobile-first, accessible (ARIA, keyboard nav, reduced-motion support)

## 🚀 Quick start

```bash
cd frontend
npm install
npm start        # http://localhost:3000
npm run build    # production build
```

## 🗂 Structure

- `frontend/` — React (Create React App) + custom CSS design system
  - `public/index.html` — app shell
  - `src/index.js` — entry point + scroll-reveal observer
  - `src/index.css` — design tokens, utilities, animations, component styles
  - `src/components/` — Navbar, Hero, SocialProof, Features, Showcase, Benefits, Testimonials, Pricing, FAQ, CTA, Footer

## 🛠 Stack

React 18 · Create React App · Vanilla CSS · IntersectionObserver · Custom microinteractions
